# Spec: Property Valuation Consultant Website (`property-valuation`)

## Business Context & Real-World User Journey
- **Target Audience**: Property owners, buyers, investors, businesses, and legal/financial partners needing professional **Property Valuation / Real Estate Appraisal & Consulting**.
- **Goal**: Establish professional credibility, clearly explain valuation services and credentials, and provide a direct, low-friction way to request a consultation or call.

## Planned Capabilities (Living Roadmap)
- **Phase 1 (Business Card Website)**:
  - Clean, authoritative single-page layout presenting credentials, types of property valued (residential, commercial, land, etc.), and how the valuation process works.
  - Direct contact channels (Phone, Messenger links, Email) + structured LocalBusiness / ProfessionalService Schema.org metadata.
- **Phase 2 (Interactive Upgrades — Optional Later)**:
  - Simple "Request a Valuation / Callback" inquiry form or chat bridge.
  - Document checklist for clients ("What documents do you need for a property appraisal?").
